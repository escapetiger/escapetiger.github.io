Use Linux in Windows: Subsystem

A major update in Windows 11 is to provide WSL2 as a more efficient and elegant solution for running Linux on Windows. By utilizing a lightweight utility virtual machine and a real Linux kernel, WSL2 bridges the gap between Windows productivity and Linux development power, providing nearly 100% system call compatibility. This note records how I set up my personal development environment in WSL2.

WSL2 + WSLg#

WSL stands for Windows Subsystem for Linux; the suffixes “2” and “g” correspond to the version number and GUI support, respectively. It is worth noting that WSL1 and WSL2 use completely different technical approaches; I personally recommend using WSL2.

For installation of WSL2 and WSLg, please refer to the official tutorial.

Windows Terminal#

Windows Terminal offers a more visually appealing terminal interface. The theme settings I use are as follows:

"colorScheme": "One Half Dark", 
"useAcrylic": true,
"acrylicOpacity": 0.8

To resolve the green highlighting issue with the ls command, please refer to this link.

Oh My Zsh#

Oh My Zsh is a visually appealing terminal theme. For specific configuration details, please refer to this post.

Note: The configuration file for zsh is ~/.zshrc, while the configuration file for bash is ~/.bashrc.

Git#

Git is a free and open-source distributed version control system widely used by software developers. Since Ubuntu comes with the appropriate version of Git pre-installed, we generally do not need to download it manually.

GitHub is a cloud-based developer platform used to create, store, manage, and share code repositories.

To use Git in the subsystem and link it to a GitHub account, we simply need to configure the SSH server. The specific steps are as follows.

  • Step 1: Generate an SSH key. Please refer to the official tutorial.
  • Step 2: Add the SSH key to your GitHub account settings.

VIM#

VIM is a highly customizable text editor. We can tailor it to our personal preferences. The default configuration file of VIM is ~/.vimrc; the key to customization is creating your own .vimrc file.

In addition to basic configuration, we can use package managers (such as Vundle) to download and manage various plugins.

Note: Performing a comprehensive configuration yourself usually consumes a lot of time and effort, especially regarding themes and development environments. Therefore, I recommend setting up your own familiar keyboard shortcuts and then using VIM plugins within other mature text editors (such as Visual Studio Code).

Visual Studio Code#

Visual Studio Code (VsCode) is a cross-platform integrated development environment (IDE) released by Microsoft. To use VsCode in a subsystem, you first need to download and install it on the main Windows system, then follow the official documentation to configure remote control for the subsystem.

Gnuplot#

Gnuplot is a simple yet powerful command-line plotting tool. To install it on an Ubuntu system, simply run the following commands:

sudo apt-get update
sudo apt-get install gnuplot

For usage of this tool, please refer to the official documentation.
