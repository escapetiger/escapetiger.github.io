摘要。 在弹性力学和黏性流体力学中，能量控制着向量场梯度的对称部分，而紧致性和适定性通常要求控制完整的梯度。 在剔除不可见的刚体运动后，Korn 不等式弥合了这一差距。本文阐述了其中的几何障碍，给出了主要的有界域估计，并利用\(H^{-1}\)中的 Poincaré-Lions 不等式，对商形式进行了详细证明。

1. Korn 不等式背后的问题#

设\(\Omega \subset \mathbb{R}^d\)、\(d \ge 2\)为一个有界、连通的区域，其边界为\(C^1\)。对于向量场\(u : \Omega \to \mathbb{R}^d\)，写出

\[ \nabla u = \varepsilon(u) + \omega(u),\qquad \varepsilon(u) := \frac{\nabla u + \nabla u^T}{2},\qquad \omega(u) := \frac{\nabla u - \nabla u^T}{2}. \]

该矩阵 \(\varepsilon(u)\) 是 对称梯度 或 线性化应变，而 \(\omega(u)\) 是 反对称梯度 或 无穷小旋转。在弗罗贝尼乌斯内积中，这两个矩阵在点上正交：

\[ \varepsilon(u) : \omega(u) = 0,\qquad \lvert \nabla u \rvert_F^2 = \lvert \varepsilon(u) \rvert_F^2 + \lvert \omega(u) \rvert_F^2. \]

因此，核心问题是：

在什么情况下，对 \(\varepsilon(u)\) 的控制意味着对整个梯度 \(\nabla u\) 的控制？

如果没有额外条件，答案是绝不会，因为对称梯度无法检测刚体运动。Korn 不等式指出，这是唯一的障碍：在边界条件或适当的投影去除了刚体运动之后，对称梯度就决定了全梯度。

该不等式源于Korn（1908）的弹性理论研究。系统性的泛函分析处理见于Duvaut 和 Lions (1976, 第三章, 第 3.3 节)，而下文采用的基于 \(H^{-1}\)的简明证明策略则见于Desvillettes 和 Villani (2002, 第 1 节)。

2. 符号与函数背景#

对于 \(u = (u_1, \ldots, u_d) \in H^1(\Omega; \mathbb{R}^d)\)，我们的约定是

\[ (\nabla u)_{ij} = \partial_j u_i,\qquad \varepsilon_{ij}(u) = \frac{\partial_j u_i + \partial_i u_j}{2},\qquad \omega_{ij}(u) = \frac{\partial_j u_i - \partial_i u_j}{2}. \]

对于矩阵 \(M, N \in \mathbb{R}^{d \times d}\)，设置

\[ M : N := \operatorname{tr}(M^T N) = \sum_{i, j = 1}^d M_{ij}N_{ij}, \qquad \lvert M \rvert_F := (M : M)^{1/2}. \]

相应的\(L^2\)范数为

\[ \lVert M \rVert_{L^2(\Omega)}^2 := \int_\Omega \lvert M(x) \rvert_F^2 \,\mathrm{d}x. \]

对于一个可积的标量、向量或矩阵值函数 \(f\)，其均值记为

\[ \langle f \rangle_\Omega := \frac{1}{\lvert \Omega \rvert}\int_\Omega f(x) \,\mathrm{d}x. \]

无穷小刚体运动的空间是

\[ \mathcal{R}(\Omega) := \left\lbrace R : \Omega \to \mathbb{R}^d \,\middle\vert\, R(x) = Ax + b,\ A^T = -A,\ b \in \mathbb{R}^d \right\rbrace. \]

平移的梯度为零，而无穷小的旋转具有恒定的反对称梯度。

3. 为什么力学模型只控制对称梯度#

3.1 线性弹性#

一个位移场 \(u\) 将参考点 \(x\) 移动到变形后的位置

\[ y(x) = x + u(x). \]

其变形梯度为\(I + \nabla u\)。欧几里得度量的诱导变化由以下公式衡量：

\[ (\nabla y)^T \nabla y - I = (I + \nabla u)^T(I + \nabla u) - I = 2\varepsilon(u) + (\nabla u)^T \nabla u. \]

在小位移范围内，忽略二次项\((\nabla u)^T\nabla u\)。因此，长度和角度的一阶变化由\(\varepsilon(u)\)表示，而非由\(\omega(u)\)表示。

对于均匀、各向同性的线弹性材料，本构关系为

\[ \sigma(u) = 2\mu\,\varepsilon(u) + \lambda\,\operatorname{tr}(\varepsilon(u))I, \]

且储能密度为

\[ W(\varepsilon(u)) = \frac{1}{2}\sigma(u) : \varepsilon(u) = \mu\lvert \varepsilon(u) \rvert_F^2 + \frac{\lambda}{2}\bigl(\operatorname{tr}\varepsilon(u)\bigr)^2. \]

标准稳定性条件

\[ \mu > 0,\qquad 2\mu + d\lambda > 0 \]

使该二次型在对称矩阵上为正定。因此，对于某个材料常数\(c_{\mathrm{el}} > 0\)，

\[ W(E) \ge c_{\mathrm{el}}\lvert E \rvert_F^2\qquad\text{for every symmetric matrix }E. \]

因此，弹性能控制 \(\varepsilon(u)\)。在排除刚体运动后，Korn 不等式将这种控制转化为对 \(u\) 的 \(H^1\) 估计。这正是该不等式在弹性力学变分理论中具有基础地位的原因之一；参见 Duvaut 和 Lions (1976)。

3.2 不可压缩的牛顿流体#

对于动力黏度为 \(\mu > 0\) 的不可压缩 Newton 流体，应力的黏性部分为

\[ \tau(u) = 2\mu\,\varepsilon(u). \]

由于对称矩阵和反对称矩阵是正交的，

\[ \tau(u) : \nabla u = 2\mu\,\varepsilon(u) : \bigl(\varepsilon(u) + \omega(u)\bigr) = 2\mu\lvert \varepsilon(u) \rvert_F^2. \]

因此，黏性耗散同样只考虑对称梯度。根据边界条件的不同，Korn 估计式将这种耗散转化为对\(\nabla u\)的控制。因此，弹性力学和流体力学中都存在同样的结构性问题(Desvillettes 和 Villani, 2002)。

4. 障碍：刚体运动#

取

\[ R(x) = Ax + b,\qquad A^T = -A. \]

然后

\[ \nabla R = A,\qquad \varepsilon(R) = \frac{A + A^T}{2} = 0. \]

如果\(A \neq 0\)，则尽管对称梯度为零，但全梯度不为零。因此，不存在如下形式的估计：

\[ \lVert \nabla u \rVert_{L^2(\Omega)} \le C\lVert \varepsilon(u) \rVert_{L^2(\Omega)} \]

对于每个 \(u \in H^1(\Omega; \mathbb{R}^d)\) 都成立。

刚体运动不仅仅是核中的例子；它们就是整个核。

命题（对称梯度的核）。 若 \(\Omega\) 连通且 \(u \in H^1(\Omega; \mathbb{R}^d)\)，则 \(\varepsilon(u) = 0\) 几乎处处成立，当且仅当 \(u \in \mathcal{R}(\Omega)\)。

非平凡方向由分布恒等式得出

\[ \partial_k\omega_{ij}(u) = \partial_j\varepsilon_{ik}(u) - \partial_i\varepsilon_{jk}(u). \tag{4.1} \]

若\(\varepsilon(u) = 0\)，则\(\omega(u)\)中每个分量的每个弱导数均为零。连通性意味着\(\omega(u)\)是一个常数反对称矩阵\(A\)。由于\(\nabla u = \omega(u) = A\)，向量场\(u - Ax\)的弱梯度为零，因此它是一个常数向量\(b\)。故\(u(x) = Ax + b\)。

这一计算已经揭示了 Korn 不等式的证明思路：利用 \(\varepsilon(u)\) 的导数控制 \(\omega(u)\) 的变化，再去除 \(\omega(u)\) 中的常数部分。

5. 三种标准形式#

文献中对“第一 Korn 不等式”和“第二 Korn 不等式”的称谓并不完全统一。更稳妥的做法是根据其归一化方式来区分各个估计；参见Desvillettes 和 Villani (2002, 方程 (1)–(3))。

5.1 齐次 Dirichlet 边界条件#

边界 Korn 不等式。 对于任意 \(u \in H_0^1(\Omega; \mathbb{R}^d)\)，

\[ \lVert \nabla u \rVert_{L^2(\Omega)}^2 \le 2\lVert \varepsilon(u) \rVert_{L^2(\Omega)}^2. \tag{5.1} \]

该版本附有简短的证明。对于\(u \in C_c^\infty(\Omega; \mathbb{R}^d)\)，经展开和分部积分可得

\[ 2\lVert \varepsilon(u) \rVert_{L^2(\Omega)}^2 = \lVert \nabla u \rVert_{L^2(\Omega)}^2 + \sum_{i, j = 1}^d\int_\Omega \partial_j u_i\,\partial_i u_j \,\mathrm{d}x = \lVert \nabla u \rVert_{L^2(\Omega)}^2 + \lVert \operatorname{div}u \rVert_{L^2(\Omega)}^2. \]

对于光滑且支撑集紧致的场，舍去非负散度项即可证明式(5.1)。\(C_c^\infty(\Omega; \mathbb{R}^d)\)在\(H_0^1(\Omega; \mathbb{R}^d)\)中的稠密性可得出该一般结论。

零迹消除了所有非零刚体运动，因此无需商空间。

5.2 低阶稳定化#

稳定化的 Korn 不等式。 存在一个 \(C = C(\Omega) > 0\)，使得每个 \(u \in H^1(\Omega; \mathbb{R}^d)\) 都满足

\[ \lVert u \rVert_{H^1(\Omega)} \le C\left(\lVert u \rVert_{L^2(\Omega)} + \lVert \varepsilon(u) \rVert_{L^2(\Omega)}\right). \tag{5.2} \]

\(L^2\)项可防止不受控的刚体运动违反该估计。这种形式在紧致性论证中尤为有用。

5.3 模去刚体运动#

模去刚体运动的 Korn 不等式。 存在常数 \(C_K = C_K(\Omega) > 0\)，使得对每个 \(u \in H^1(\Omega; \mathbb{R}^d)\)，均有

\[ \inf_{R \in \mathcal{R}(\Omega)}\lVert \nabla(u - R) \rVert_{L^2(\Omega)} \le C_K\lVert \varepsilon(u) \rVert_{L^2(\Omega)}. \tag{5.3} \]

同样地，在也选定\(R\)的平移部分之后，

\[ \inf_{R \in \mathcal{R}(\Omega)}\lVert u - R \rVert_{H^1(\Omega)} \le C_K'\lVert \varepsilon(u) \rVert_{L^2(\Omega)}. \tag{5.4} \]

我们将证明估计式（5.3）。它精确地表达了 Korn 不等式的几何含义：\(\varepsilon(u)\)控制了从\(u\)到刚体运动的有限维空间的距离。

6. 泛函分析引擎：一个 Poincaré–Lions 估计#

6.1 \(H^{-1}\)范数#

设 \(H^{-1}(\Omega)\) 为 \(H_0^1(\Omega)\) 的对偶。我们使用等价范数

\[ \lVert f \rVert_{H^{-1}(\Omega)} := \sup\left\lbrace \lvert \langle f, \varphi \rangle \rvert \,\middle\vert\, \varphi \in C_c^\infty(\Omega),\ \lVert \nabla\varphi \rVert_{L^2(\Omega)} \le 1 \right\rbrace. \]

基于\(H_0^1(\Omega)\)的 Poincaré 不等式使得该范数等价于基于\(\lVert \varphi \rVert_{H^1}\)的通常对偶范数。

对于 \(g \in L^2(\Omega)\)，分布微分得

\[ \langle \partial_i g, \varphi \rangle = -\int_\Omega g\,\partial_i\varphi \,\mathrm{d}x. \]

因此，

\[ \lVert \partial_i g \rVert_{H^{-1}(\Omega)} \le \lVert g \rVert_{L^2(\Omega)}. \tag{6.1} \]

对于向量分布 \(F = (F_1, \ldots, F_d)\)，定义

\[ \lVert F \rVert_{H^{-1}(\Omega)}^2 := \sum_{i = 1}^d\lVert F_i \rVert_{H^{-1}(\Omega)}^2. \]

6.2 Lions 正则性估计#

以下分布结果是关键的分析依据。

Lions 引理。 若 \(f \in H^{-1}(\Omega)\)，且对每个 \(i = 1, \ldots, d\) 均有 \(\partial_i f \in H^{-1}(\Omega)\)，则 \(f \in L^2(\Omega)\)。此外，

\[ \lVert f \rVert_{L^2(\Omega)} \le C_L(\Omega)\left(\lVert f \rVert_{H^{-1}(\Omega)} + \lVert \nabla f \rVert_{H^{-1}(\Omega)}\right). \tag{6.2} \]

这一结果见 Duvaut 和 Lions (1976，第三章，定理 3.2，第 111 页；注 3.1，第 112 页)。它是关于分布的正则性定理：通过负阶 Sobolev 范数控制一阶导数，即可恢复 \(L^2\) 估计。

6.3 Poincaré-Lions 不等式#

引理（Poincaré–Lions）。 存在一个 \(C_{\mathrm{PL}} = C_{\mathrm{PL}}(\Omega) > 0\)，使得每个 \(f \in L^2(\Omega)\) 都满足

\[ \lVert \nabla f \rVert_{H^{-1}(\Omega)}^2 \le d\lVert f - \langle f \rangle_\Omega \rVert_{L^2(\Omega)}^2 \le C_{\mathrm{PL}}\lVert \nabla f \rVert_{H^{-1}(\Omega)}^2. \tag{6.3} \]

Desvillettes 和 Villani (2002，引理 2) 明确使用了这一表述。

证明。 设 \(g = f - \langle f \rangle_\Omega\)。由于 \(\partial_i f = \partial_i g\)，式(6.1)的估计结果为

\[ \lVert \nabla f \rVert_{H^{-1}(\Omega)}^2 = \sum_{i = 1}^d\lVert \partial_i g \rVert_{H^{-1}(\Omega)}^2 \le d\lVert g \rVert_{L^2(\Omega)}^2. \]

反向估计才是难点。假设该推断是错误的。那么就存在一个\(f_n \in L^2(\Omega)\)，使得

\[ \langle f_n \rangle_\Omega = 0,\qquad \lVert f_n \rVert_{L^2(\Omega)} = 1,\qquad \lVert \nabla f_n \rVert_{H^{-1}(\Omega)} \longrightarrow 0. \]

取子列后，有 \(f_n \rightharpoonup f\) 于 \(L^2(\Omega)\)。由于 \(\Omega\) 有界，嵌入 \(L^2(\Omega) \hookrightarrow H^{-1}(\Omega)\) 是紧的；它与紧嵌入 \(H_0^1(\Omega) \hookrightarrow L^2(\Omega)\) 互为对偶。因此

\[ f_n \longrightarrow f\qquad\text{strongly in }H^{-1}(\Omega). \]

\(\nabla f_n\) 的分布极限既是 \(\nabla f\)，也是零，因此 \(\nabla f = 0\)。\(\Omega\) 的连通性意味着 \(f\) 是常数。\(L^2\) 的弱收敛性保持了均值为零的条件，因此 \(f = 0\)。我们已经证明了 \(f_n \to 0\) 在 \(H^{-1}(\Omega)\) 中成立。现在应用（6.2）可得

\[ 1 = \lVert f_n \rVert_{L^2(\Omega)} \le C_L(\Omega)\left(\lVert f_n \rVert_{H^{-1}(\Omega)} + \lVert \nabla f_n \rVert_{H^{-1}(\Omega)}\right) \longrightarrow 0, \]

这自相矛盾。因此，反向不等式成立。\(\square\)

7. 模去刚体运动的 Korn 不等式的证明#

该证明分为两步。首先，我们控制无穷小旋转中的非常数部分。然后，我们确定使到\(\nabla u\)的距离最小的常数旋转。

7.1 一个导数恒等式#

设

\[ E := \varepsilon(u),\qquad W := \omega(u). \]

对于每个 \(i, j, k \in \left\lbrace 1, \ldots, d \right\rbrace\)，通过交换分布导数可得

\[ \partial_k W_{ij} = \frac{1}{2}\left(\partial_k\partial_j u_i - \partial_k\partial_i u_j\right) = \partial_j E_{ik} - \partial_i E_{jk}. \tag{7.1} \]

该恒等式有时被称为证明中的“Schwarz 定理步骤”。它是论证的代数核心：反对称部分的每个导数都是对称部分导数的线性组合。Carrapatoso 等 (2022，式 (23)) 也强调了这一恒等式。

7.2 对旋转的非常数部分的控制#

将式(6.3)中的逆不等式应用于每个标量分量\(W_{ij}\)：

\[ \lVert W - \langle W \rangle_\Omega \rVert_{L^2(\Omega)}^2 \le C_{\mathrm{PL}}\sum_{i, j, k = 1}^d\lVert \partial_k W_{ij} \rVert_{H^{-1}(\Omega)}^2. \tag{7.2} \]

根据（7.1）、三角不等式以及（6.1），

\[ \lVert \partial_k W_{ij} \rVert_{H^{-1}(\Omega)}^2 \le 2\lVert \partial_j E_{ik} \rVert_{H^{-1}(\Omega)}^2 + 2\lVert \partial_i E_{jk} \rVert_{H^{-1}(\Omega)}^2 \le 2\lVert E_{ik} \rVert_{L^2(\Omega)}^2 + 2\lVert E_{jk} \rVert_{L^2(\Omega)}^2. \]

对 \(i, j, k\) 求和，结果为

\[ \sum_{i, j, k = 1}^d\lVert \partial_k W_{ij} \rVert_{H^{-1}(\Omega)}^2 \le 4d\lVert E \rVert_{L^2(\Omega)}^2. \]

因此，

\[ \lVert W - \langle W \rangle_\Omega \rVert_{L^2(\Omega)}^2 \le 4dC_{\mathrm{PL}}\lVert E \rVert_{L^2(\Omega)}^2. \tag{7.3} \]

这里的 \(H^{-1}\) 范数至关重要：当 \(u \in H^1\) 时，\(E\) 的导数未必属于 \(L^2\)，但总属于 \(H^{-1}\)。

7.3 最优刚体旋转#

设\(A\)为任意常数反对称矩阵。由于\(E\)是对称矩阵，而\(W - A\)是反对称矩阵，

\[ \lVert \nabla u - A \rVert_{L^2(\Omega)}^2 = \lVert E \rVert_{L^2(\Omega)}^2 + \lVert W - A \rVert_{L^2(\Omega)}^2. \tag{7.4} \]

均值矩阵 \(\langle W\rangle_\Omega\) 本身也是反对称的。将其正交分解为零均值部分与常数部分，可得

\[ \lVert W - A \rVert_{L^2(\Omega)}^2 = \lVert W - \langle W \rangle_\Omega \rVert_{L^2(\Omega)}^2 + \lvert \Omega \rvert\,\lvert \langle W \rangle_\Omega - A \rvert_F^2. \tag{7.5} \]

因此，唯一的最小化矩阵是

\[ A_* = \langle \omega(u) \rangle_\Omega. \tag{7.6} \]

将（7.3）至（7.6）式结合起来，可得

\[ \inf_{A^T = -A}\lVert \nabla u - A \rVert_{L^2(\Omega)}^2 \le \left(1 + 4dC_{\mathrm{PL}}\right)\lVert \varepsilon(u) \rVert_{L^2(\Omega)}^2. \]

由于 \(\nabla(Ax + b) = A\)，平移向量 \(b\) 不会影响该梯度最小化。这证明了式(5.3)。

要得到（5.4），选择\(A = A_*\)，然后设置

\[ b_* := \langle u - A_*x \rangle_\Omega. \]

向量场 \(u - (A_\ast x + b_\ast)\) 的均值为零，故通常的 Poincaré 不等式可用 \(\lVert \nabla u - A_* \rVert_{L^2}\) 控制其 \(L^2\) 范数。这补足了零阶控制，完成了 \(H^1\) 商空间估计。\(\square\)

8. 在其他约束条件下，哪些方面会发生变化？#

8.1 切向边界条件与轴对称性#

边界条件并不一定需要消除所有的刚体运动。例如，切线条件

\[ u \cdot n = 0\qquad\text{on }\partial\Omega \]

仍可能存在一个与边界相切的刚性旋转。这种情况发生在轴对称区域上。Desvillettes 和 Villani 证明，当几何结构排除了这种非零的切向刚体运动时，相应的 Korn 估计式在无需减去刚性旋转的情况下仍然成立；在轴对称的情况下，必须将残留的旋转模投影出去。 他们的定量分析源于动理学而非弹性力学(Desvillettes 和 Villani, 2002)。

这个教训具有普遍意义：边界条件只有在能够排除与该条件兼容的核的情况下，才具有实用价值。

8.2 整个空间上的加权不等式#

在\(\mathbb{R}^d\)上，无法直接将无权重 Poincaré 和 Korn 估计式从有界区域复制过来。一个具有约束作用的测度

\[ \mathrm{d}\mu(x) = Z^{-1} e^{-\phi(x)} \,\mathrm{d}x \]

能够提供所需的强制性。在对 \(\phi\) 施加明确的归一化、正则性和 Poincaré 条件后，Carrapatoso 等 (2022) 通过投影去除适当的有限维刚体运动模态，建立了加权 Korn 不等式和 Poincaré-Korn 不等式，并将这些估计与由 Witten 拉普拉斯算子构成的自伴算子联系起来。

他们的论证保留了与有界域证明相同的结构：

  1. 分离出有限维对称模；
  2. 使用加权 Poincaré 不等式或 Poincaré-Lions 不等式；
  3. 利用导数恒等式 (7.1)，用对称部分的导数代替反对称部分的导数。

因此，这个有界域上的初等证明并非孤立技巧，而是动理学与亚强制性理论中更广泛的强制性机制的一个原型。

9. 常见的误解#

  • 若未进行归一化处理，对称梯度无法确定位移。 平移对 \(\nabla u\) 而言是不可见的，而无穷小的旋转对 \(\varepsilon(u)\) 而言是不可见的。

  • Korn 不等式并不声称反对称部分逐点很小。 它说明：减去一个常数反对称矩阵后，反对称部分的 \(L^2\) 范数可由对称部分控制。

  • 区域假设至关重要。 连通性保证零梯度函数为单个常数，边界正则性则保证 Poincaré-Lions 估计所需的紧性与局部化结果。

  • Korn 常数依赖于几何。 在切向边界条件下，当区域趋于轴对称时，该常数可能退化；Desvillettes 和 Villani (2002) 对其关于区域 \(\Omega\) 的形状依赖给出了定量分析。

  • 仅凭名称并不可靠。 不同来源将“第一”和“第二”分别对应于不同的归一化形式。务必检查边界条件、低阶项以及模去刚体运动的条件。

10. 最终展望#

Korn 不等式是一个具有几何核的强制性定理。与能量相关的张量\(\varepsilon(u)\)会忽略无穷小的刚体运动，但除此之外不会忽略任何其他内容。该证明通过一个简洁的推导链对此进行了精确阐述：

\[ \varepsilon(u) \xrightarrow{\text{differentiate}} \nabla\omega(u) \xrightarrow{\text{Poincaré--Lions}} \omega(u) - \langle \omega(u) \rangle_\Omega \xrightarrow{\text{orthogonal projection}} \nabla u - \langle \omega(u) \rangle_\Omega. \]

每个箭头都发挥着独特的作用。导数恒等式提供了代数基础，\(H^{-1}\)估计避免了对二阶正则性的要求，而投影则消除了有限维对称性。这种组合解释了为什么 Korn 不等式既是连续介质力学的基本工具，也是现代加权和动理学强制性估计的可复用模板。
