辐射输运问题研究辐射能量在背景介质中的传播及其与物质之间的相互作用过程。

辐射模型#

光子是传输辐射能量的基本粒子。单个光子的能量为 \(h\nu\)，动量为 \(\frac{h\nu}{c}\)，其中 \(c\) 为光速，\(h\) 为普朗克常数。在固定时刻 \(t\)，光子的运动状态可由位置 \(x\in\mathbb{R}^3\)，传播方向 \(\Omega\in\mathbb{S}^2\) 和频率 \(\nu\in\mathbb{R}\) 表征。这里，\(\mathbb{R}^3\) 表示三维欧几里得空间，\(\mathbb{S}^{2}\) 表示嵌入于 \(\mathbb{R}^3\) 中的单位球面。

辐射能量可通过光子的数量分布来刻画。记相空间变量为

\[ z = (x,\Omega,\nu), \]

光子的分布函数为

\[ f(t,x,\Omega,\nu). \]

辐射场的能量分布可由辐射强度 \(I\) 描述

\[ I(t,x,\Omega,\nu) = c h \nu f(t,x,\Omega,\nu). \]

其物理意义为：在时刻 \(t\)，位置 \(x\) 处沿方向 \(\Omega\) 传播，频率为 \(\nu\) 的辐射在单位时间、单位面积、单位立体角以及单位频率区间内所携带的能量。

辐射能量的输运过程通常可分解为两类基本机制：自由输运与光子–介质相互作用。一方面，光子在介质中自由运动，引起辐射能量在物理空间中的传输；另一方面，光子在运动过程中会与背景介质发生相互作用，导致辐射场与介质之间的能量交换，其主要过程包括：

吸收（absorption）#

光子穿过介质时被吸收并消失，使能量由辐射场向介质转移。吸收过程可由吸收系数

\[ \sigma_a(t,x,\nu) \]

定量描述，其表示光子在单位传播路径内被吸收的概率。

散射（scattering）#

光子穿过介质后改变运动方向和频率继续运动。散射过程保持光子数守恒，但会重新分配在方向与频率空间中的分布。若散射过程中光子频率保持不变，则称为相干散射；若散射在方向上各向同性，则称为各向同性散射。散射过程可由散射系数

\[ \sigma_s(t,x,\Omega\cdot\Omega',\nu\to\nu') \]

定量描述，其表示在单位传播路径内，方向为 \(\Omega\)、频率为 \(\nu\) 的光子散射成方向为 \(\Omega'\)、频率为 \(\nu'\) 的光子的概率。

发射（emission）#

介质由于热运动或其他微观机制会产生新的光子，使能量由介质向辐射场转移。对于各向同性介质，发射过程可由源项

\[ S(t,x,\nu) \]

定量描述，其表示单位时间内发射出的、频率为 \(\nu\) 的光子数量。

在上述物理机制的共同作用下，辐射强度 \(I\) 的时间演化可通过下列辐射输运方程描述：

\[ \frac{1}{c}\partial_t I + \Omega\cdot\nabla_x I = \mathcal{C}_s(I) + \mathcal{C}_a(I). \]

其中散射算子为（各向同性相干散射）

[ \mathcal{C}_s(I)

\sigma_s(\Pi(I)-I), ]

[ \Pi(I)

\frac{1}{4\pi} \int_{\mathbb{S}^2} I, d\Omega. ]

吸收与发射算子为

[ \mathcal{C}_a(I)

\sigma_a I + S. ]

辐射输运方程中需要求解的辐射强度 \(I\) 是依赖于时间 \(t\)，位置 \(x\)，方向 \(\Omega\) 和频率 \(\nu\) 的七维函数，直接计算代价极高。因此，我们需要进行降维处理。

多群模型#

在频率维度上，辐射输运方程的模型降维方法主要有两种：多群模型（multigroup model）与多带模型（multiband model）。两种方法均通过将频率区间划分为若干子区间来降低模型复杂度，其区别在于划分依据的不同：多群模型按照频率大小进行划分，而多带模型则依据吸收系数等介质光学性质进行划分。

以多群模型为例，首先将频率区间

\[ [0,+\infty) \]

截断为有限区间

\[ [0,\nu_{\max}], \]

并进一步将其划分为

\[ [\nu_{g-\frac12},\nu_{g+\frac12}], \quad g = 1,2,\dots,G, \]

其中

\[ \nu_{\frac12}=0, \quad \nu_{G+\frac12}=\nu_{\max}. \]

对辐射输运方程关于频率 \(\nu\) 在 \([\nu_{g-\frac12},\nu_{g+\frac12}]\) 上积分，可得第 \(g\) 个频率区间对应的方程：

[ \frac{1}{c}\partial_t I_g + \Omega\cdot\nabla_x I_g

\sigma_{s,g}(\Pi(I_g)-I_g)#

\sigma_{a,g} I_g + S_g. ]

其中

[ I_g

\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} I, d\nu, ]

[ S_g

\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} S, d\nu. ]

散射系数与吸收系数定义为

[ \sigma_{s,g}

\frac{\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} \sigma_s(\Pi(I)-I), d\nu} {\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} (\Pi(I)-I), d\nu}, ]

[ \sigma_{a,g}

\frac{\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} \sigma_a I, d\nu} {\int_{\nu_{g-\frac12}}^{\nu_{g+\frac12}} I, d\nu}. ]

特别地，当 \(G=1\) 时，对应的模型称为灰体模型（gray model）；当仅考虑某一个特定频率子区间时，则称为单群模型（one-group model）。本文后续将主要关注单群情形下的辐射输运模型。

宏观扩散极限#

为分析不同物理机制在系统演化中的相对重要性，下面对辐射输运方程进行无量纲化处理。设光子平均自由程、特征空间尺度和特征时间尺度分别为 \(\bar{\ell}\)、\(\bar{x}\) 和 \(\bar{t}\)，并引入如下无量纲变量与参数：

\[ \begin{aligned} x &= x'\bar{x}, \\ t &= t'\bar{t}, \\ \sigma_s &= \frac{\sigma_s'}{\bar{\ell}_s}, \\ \sigma_a &= \frac{\sigma_a'}{\bar{\ell}_a}, \\ S &= \frac{S'}{\bar{\ell}_q}. \end{aligned} \]

其中带单引号的量表示对应的无量纲变量，而 \(\bar{\ell}_s\)、\(\bar{\ell}_a\) 与 \(\bar{\ell}_q\) 分别表示散射、吸收及发射事件对应的平均自由程。

引入无量纲参数 \(\varepsilon\) 表示光子的平均自由程与特征空间尺度之比，定义为

[ \varepsilon

\frac{\bar{\ell}}{\bar{x}}. ]

为研究系统的长时间演化行为，我们对时间维度进行拉伸，即

[ \varepsilon \bar{t}

\frac{\bar{x}}{c}. ]

这表明观测时间尺度远大于光子穿越宏观空间尺度所需的时间。

另外，我们特别关注辐射能量在光学厚区域中的输运行为。在该区域中，散射的平均自由程远小于吸收和发射的平均自由程：

[ \frac{\bar{\ell}}{\bar{\ell}_s}

1, ]

[ \frac{\bar{\ell}}{\bar{\ell}_a}

\frac{\bar{\ell}}{\bar{\ell}_q}#

\varepsilon^2. ]

基于上述假设，我们将无量纲变换代入辐射输运方程，并略去单引号以简化记号，可得到如下多尺度形式的辐射输运方程：

[ \varepsilon^2 \partial_t I + \varepsilon \Omega\cdot\nabla_x I

\sigma_s(\Pi(I)-I)#

\varepsilon^2 \sigma_a I + \varepsilon^2 S. ]

为分析该模型在 \(\varepsilon \to 0\) 时的渐近行为，我们采用形式 Hilbert 展开，将

[ I

\sum_{k=0}^{\infty} \varepsilon^k I^{(k)}, ]

代入上述方程中，可得不同阶次的方程。

\(O(1)\) 阶#

[ I^{(0)}

\Pi(I^{(0)}). ]

\(O(\varepsilon)\) 阶#

[ \Omega\cdot\nabla_x I^{(0)}

\sigma_s \left( \Pi(I^{(1)})

I^{(1)} \right). ]

\(O(\varepsilon^2)\) 阶#

[ \partial_t I^{(0)} + \Omega\cdot\nabla_x I^{(1)}

\sigma_s \left( \Pi(I^{(2)})

I^{(2)} \right)

\sigma_a I^{(0)} + S. ]

再对上述 \(O(\varepsilon^2)\) 方程应用角变量平均算子

[ \langle \cdot \rangle

\frac{1}{4\pi} \int_{\mathbb{S}^2} (\cdot), d\Omega, ]

并结合前两阶方程，可以推出 \(I^{(0)}\) 满足如下扩散型方程：

[ \partial_t I^{(0)}

\nabla_x\cdot \left( \frac{1}{3\sigma_s} \nabla_x I^{(0)} \right)

\sigma_a I^{(0)} + S. ]

综上所述，在扩散尺度变换下，当 \(\varepsilon \to 0\) 时，多尺度辐射输运模型在形式上退化为宏观扩散模型。
