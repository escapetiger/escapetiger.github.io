在 Windows 中使用 Linux：子系统

Windows 11 的一项重要更新是引入了 WSL2 功能，为在 Windows 上运行 Linux 提供一种更加高效且优雅的解决方案。相较于传统的双系统或虚拟机方案，WSL2 通过轻量级虚拟化技术，在保证性能的同时，实现了对 Linux 环境的深度支持，从而显著提升了开发与科研工作的便利性。本笔记介绍我使用 WSL2 搭建开发环境的过程及遇到的问题。

WSL2 + WSLg#

WSL 是 Windows Subsystem for Linux 的简称，后缀 2 和 g 分别对应于版本号与GUI界面支持。需要注意的是，WSL1 和 WSL2 采用的是完全不同的技术路线，个人推荐使用 WSL2。

关于 WSL2 和 WSLg 的安装，可参考官方教程。

Windows terminal#

Windows terminal 可以提供更加美观的终端界面。笔者采用的主题设置如下：

"colorScheme": "One Half Dark", 
"useAcrylic": true,
"acrylicOpacity": 0.8

为解决 ls 指令的绿色高亮问题，可参考这里。

Oh my zsh#

Oh my zsh 是一款很好看的终端主题，具体设置可参考推文。

注： zsh 的配置文件是~/.zshrc, 而 bash 的配置文件是~/.bashrc。

GIT#

Git 是一个免费且开源的分布式版本管理系统，是软件开发者广泛使用的一项工具。由于ubuntu系统自带对应版本的Git，我们一般不用去手动下载它。

Github 是一个云端开发者平台，可用于创建、存储、管理和分享自己的代码仓库。

要在子系统中使用 Git 并绑定 Github 账号，我们只需要配置好 ssh 服务器即可，具体步骤如下。

步骤 1: 生成 ssh 密钥，请参考官方教程。

步骤 2: 添加 ssh 密钥到 Github 账号设置。

VIM#

VIM 是一款可高度自定义的文本编辑器。我们可以根据自己的喜好对它进行私人定制。

VIM 的默认配置文件是 ~/.vimrc，定制的关键就是写一份自己的 .vimrc 文件。

除基础配置外，我们可以通过插件管理系统（如 Vundle）来下载和管理各种插件。

注： 自己进行全面配置通常要花费大量的时间精力，尤其是主题和开发环境等方面。因此，笔者更推荐配置好自己熟悉的快捷键，然后在其它成熟的文本编辑器（如 Visual Studio Code）中使用 VIM 插件。

Visual Studio Code#

Visual Studio Code (VsCode) 是微软推出的跨平台集成开发环境。要在子系统中使用 VsCode，我们首先需要在 Windows 主系统中进行下载安装，然后参考官方文档配置子系统的远程控制。

Gnuplot#

Gnuplot 是一款简洁又强大的命令行绘图工具。在 Ubuntu 系统中安装只需要运行以下指令：

sudo apt-get update
sudo apt-get install gnuplot

关于该工具的使用，请参考官方文档。
